VaultRAG — Privacy-first document Q&A built end-to-end on Cloudflare's edge
Small law firms, healthcare clinics, and compliance teams need AI document search but legally cannot send confidential files to third-party AI providers. The default RAG stack (OpenAI + Pinecone) is disqualifying for HIPAA, attorney-client privilege, and GDPR-sensitive workflows. Self-hosted alternatives (PrivateGPT, LlamaIndex) require GPU infrastructure no 30-person firm can manage. Enterprise platforms (Glean, Copilot) cost six figures.
VaultRAG closes the gap. Users upload PDFs, ask questions, and get cited answers — without a single byte ever leaving Cloudflare's network.
The system runs on ten Cloudflare products doing structural work: Workers (Hono backend with JWT auth), Workers AI (BGE embeddings + Llama 3.1 8B inference, all on Cloudflare GPUs), Vectorize (768-dim vector store with metadata-indexed tenant filtering), R2 (tenant-prefixed PDF storage), D1 (multi-tenant SQL for users, documents, chunks, chats, audit log), AI Gateway (per-call observability and caching), KV (semantic answer cache), Pages (React frontend), CDN/Cache API (edge asset delivery), and Workers Secrets (encrypted JWT signing key).
Tenant isolation is enforced at four redundant layers: JWT-bound tenant_id (cannot be forged), R2 key prefixes, Vectorize metadata filters on indexed tenant_id, and D1 WHERE clauses. Bypassing one layer hits the next. Demo: two tenants logged in side by side, asking the same question — one gets cited answers, the other gets "no results found." Provable isolation in 30 seconds.
Auth hardening: PBKDF2-SHA256 (100k iterations), per-user salts, constant-time compare, anti-enumeration, 7-day JWT expiry. Every sensitive action audit-logged with IP and user agent for compliance review.
This architecture wasn't buildable two years ago. Workers AI + Vectorize + AI Gateway shipped in 2023-2024 and made single-vendor edge RAG real. VaultRAG is what that unlocks.
